# BacklotHub: G2 architektúra-tervek, G3 nyilvántartás, V1 mérés

Tulajdonosi jóváhagyás: István, 2026-11-21 (G2-01–G2-26, G3 nyilvántartás, proxyszabvány). Csak dokumentáció,
implementáció nincs. A G1 (funkcionális követelmények) jelentései és a nyitott-kérdés lista a BacklotHub
projektmappájában vannak; az egyes G2-k hivatkozásai ezekre ott érvényesek.

- `CFA4-BACKLOTHUB-G2-01…26-*.md`: lépcsőnkénti architektúra (adatmodell, parancsok, hibakódok, események, licenc).
- `CFA4-BACKLOTHUB-G2-13-26-OSSZEFOGLALO-2026-11-21.md`: a 13–26. lépcső összefoglalója és az eltérések a G1-től.
- `CFA4-BACKLOTHUB-G3-FUGGOSEG-ES-LICENCNYILVANTARTAS-2026-11-21.md`: függőségek és licencek lépcsőnként.
- `CFA4-BACKLOTHUB-V1-PROXY-MERES-2026-11-21.md`: CPU-only proxy-mérés (előzetes), a proxyszabvány alapja.
- Kapcsolódó ADR-ek: [ADR-0006](../../adr/ADR-0006-backlothub-postgresql.md), [ADR-0007](../../adr/ADR-0007-media-services.md), [ADR-0009](../../adr/ADR-0009-cfa4-file-services.md), [ADR-0016](../../adr/ADR-0016-backlothub-konfliktuskezeles.md).
- Hátravan a 8. lépcső G4 kapuja előtt: REV-05 A/V-szinkron mérés és a CFA4-MIN gépen végzett mérés.
