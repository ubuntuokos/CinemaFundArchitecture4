# cfa4-av2

Clean-room AV2 bitstream parsing from the AV2 Bitstream & Decoding Process Specification v1.0.0
(native track B of `docs/plans/AV2-CODEC-PLAN-2026-10-29.md`, step AV2-04). L0: depends only on
`cfa4-bitstream`.

| Stage | Status |
|---|---|
| Annex B framing, `leb128()` (§ 4.10.5, Annex B.2) | done |
| OBU header and extension (§ 5.2.2, Table 6.1) | done |
| Sequence header, leading fields up to the cropping window (§ 5.4.1) | done |
| Sequence header tool syntax: decoder model, layer dependency maps, partition, segment, intra, inter, screen content, transform/quantizer/entropy, filter and tile configuration, film grain flag, extension flag and trailing bits (§ 5.4.1–5.4.13) | done; all 13 AVM corpus headers end exactly at their trailing bits |
| Tile layout `tile_params()` (§ 5.18.7.3–5.18.7.7) | done (sequence and frame header) |
| Frame header (`frame_header_info()` § 5.18 through `film_grain_config()`): key, intra-only, inter, switch and RAS frames, including reference selection (`get_ref_frames`, § 7.7), past/future lists, primary reference, TIP frames and TIP output frames, frame size with refs, motion modes, MV precision, interpolation filter, frame size, quantizer, segmentation, quantizer matrices, delta q, lossless, deblocking, GDF, CDEF, loop restoration modes and unit sizes, CCSO (with reuse), tx mode, reference select, skip mode, BAWP, warp MV, film grain id/seed; `tile_group_obu()` up to the tile data (§ 5.19: tile range, tile sizes) | done; every frame header of the 13 corpus vectors has the reference decoder's length (`NumFrameHeaderBits`), `base_q_idx`, order hint and tile grid, (including the RAS frames), and the tile data fills each OBU exactly. Not yet (each returns `Unsupported`): open-loop key, leading, show-existing and bridge frames, BRU, multi-frame headers, global motion, frame-level Wiener filter banks |
| Stream scope check (`probe_annexb`: no MSDO, no extended or embedded layers) | done |
| Symbol decoder (§ 8.2: init, read_symbol with CDF adaptation, read_bool, read_literal, exit checks) | implemented from the spec text; unit-tested only, bit-exactness is proven once tiles decode against the AVM oracle |
| Default CDF tables (§ 9.3, 180 tables), `cdf_default.rs`, generated by `scripts/dev/av2-cdf-tables.py` from the spec attachments (not committed) | done; shape and CDF well-formedness tested (monotone values, rate index, zero counter) |
| CDF selection (§ 8.3), CDF init/averaging/save-load, operating point set, tile decoding | not started |

Tests: unit tests per module; `tests/fuzz_hostile.rs` truncates and mutates a synthetic stream and,
when present, the AVM corpus in `target/fixtures/av2/vectors` (`scripts/dev/av2-oracle.py corpus`)
and checks that the corpus sequence headers parse completely (geometry, tiles, film grain) and that
the frame headers match the values the instrumented AVM v1.0.0 decoder reports (`NumFrameHeaderBits`,
`base_q_idx`, order hint, tile grid; the quantizer of TIP output frames is derived after the reference decoder prints it). Nothing may panic on hostile input.
